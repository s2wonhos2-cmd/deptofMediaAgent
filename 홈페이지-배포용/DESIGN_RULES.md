# 경희 미디어 업무 자동화 Portal — 디자인 규칙

작성일: 2026-08-31. 이 문서는 본 프로젝트의 구현 기준이며, 경희대학교가 발행한 공식 UI 매뉴얼을 대체하지 않는다.

## 1. 분석 근거

- [경희대학교 University Identity](https://www.khu.ac.kr/kor/user/contents/view.do?menuNo=200028): 대학 상징의 역할과 체계를 확인했다. 대학휘장은 공식 대표 상징이며, 워드마크와 캐릭터는 보조 요소다.
- [대학 휘장 및 색상 활용](https://www.khu.ac.kr/kor/user/contents/view.do?menuNo=200029): 단색 휘장의 기본색은 Red이며 배경에 맞는 타입을 선택하도록 안내한다. 색상 예시는 Kyung Hee Red, Kyung Hee Blue, Cool Gray, Silver다.
- [공식 색상 활용 이미지](https://www.khu.ac.kr/upload/cross/images/000001/imgSub0424.jpg): 로컬 `khu-official-colors.jpg`에 참고본을 보관했다.
- 공식 홈페이지의 [base.css](https://www.khu.ac.kr/resources/user/_common/_css/base.css), [common.css](https://www.khu.ac.kr/resources/user/_common/_css/common.css), [contents.css](https://www.khu.ac.kr/resources/user/_common/_css/contents.css)를 직접 확인했다. `#ab1a23`, `#990e17`, `#1a2332`, `#b49759`, `#faf9f5`가 실제 스타일에 등장한다. 본문은 Roboto·notokr·Malgun Gothic 계열, 일부 영문 강조는 Merriweather 계열을 사용한다.

## 2. 공식 근거와 프로젝트 해석의 구분

휘장 역할, 단색 Red 원칙, 색상 이름은 공식 자료에 근거한다. 아래 HEX 값은 공식 웹사이트 CSS에서 채택한 웹 구현 색상이며 인쇄용 Pantone/CMYK 지정값이라고 주장하지 않는다. 카드 배치, 여백, 모서리, 반응형 기준은 업무 포털을 위한 자체 디자인 규칙이다.

## 3. 색상 토큰

| 토큰 | 값 | 사용 |
| --- | --- | --- |
| `--khu-red` | `#ab1a23` | 활성 업무 카드, 주요 강조 |
| `--khu-red-dark` | `#990e17` | 호버·강조 상태 |
| `--khu-ink` | `#1a2332` | 주요 텍스트·사진 위 명암 |
| `--khu-gold` | `#b49759` | 얇은 장식선과 작은 포인트 |
| `--paper` | `#faf9f5` | 페이지 바탕 |
| `--surface` | `#ffffff` | 카드·상단 브랜드 영역 |
| `--muted` | `#666b73` | 보조 설명, 준비 중 텍스트 |
| `--line` | `#e4e2df` | 구획선 |

금색은 작은 본문 텍스트의 단독 색상으로 사용하지 않는다. 상태는 색상뿐 아니라 문구와 아이콘으로 구분한다.

## 4. 이미지·휘장

- Hero는 사용자가 제공한 `khhu-main.jpeg`만 사용한다. 상단 제목의 실제 배경으로 배치하고 어두운 그라데이션으로 읽기성을 확보한다.
- 휘장은 `대학휘장-02.jpg` 원본을 사용한다. 외곽 흰 여백만 CSS 표시창에서 제외하고 상징과 영문 표기는 자르거나 변형·재채색하지 않는다. 흰 배경을 유지한다.
- `대학휘장-01.jpg`는 보조 참고 자료로 원본 보존한다.
- 생성형 이미지로 공식 휘장을 재현하거나 새로운 공식 시그니처를 만들지 않는다.

## 5. 화면과 타이포그래피

- PC는 상단 브랜드 영역 → 사진과 제목 → 사용자 유형 탭 → 4열 × 3행 업무 타일 → 이용 안내 → 하단 정보 순서다.
- 기본 목표는 브라우저 콘텐츠 영역 1280×720 이상, 확대율 100%에서 세로 스크롤 없이 전체 표시다. 1366×768, 1440×900, 1920×1080도 같은 구조를 유지한다.
- 높이에 따라 Hero와 카드의 높이를 `clamp()`로 조절한다. 650px 미만 콘텐츠 높이, 확대 보기, 모바일에서는 내용을 숨기지 않고 자연스러운 스크롤을 허용한다.
- 가로 1000px 미만은 2열, 640px 미만은 1열이다. 작은 화면에서는 고정 높이를 해제한다.
- 본문은 외부 다운로드 없이 `Malgun Gothic`, `Apple SD Gothic Neo`, 시스템 sans-serif를 사용한다. 영문 브랜드 보조 표기는 Georgia 계열을 사용한다. 공식 로고타입이라고 주장하지 않는다.
- 제목은 30–44px, 카드 제목은 18–21px, 설명은 13–14px. 모서리는 4–8px로 절제한다.

## 6. 업무 카드와 동작

| 탭 | 첫 타일 | 동작 |
| --- | --- | --- |
| 학생용 | 졸업논문 제출 | 링크 없음. 비활성·준비 중 |
| 교수용 | 교수 연구실적 제출 | `https://docs.google.com/forms/d/e/1FAIpQLSfhfIHhjAdBqlYiGF_Q7DgjjftBQHyvnwoF_IseIddnbtpEFw/viewform`로 같은 탭에서 이동 |
| 범용 | 업데이트 예정 | 링크 없음. 비활성·준비 중 |

- 교수용 첫 타일은 붉은 배경과 '이용 가능', '제출 페이지로 이동' 문구를 사용한다. 상태는 링크 연결 여부를 뜻하며 외부 서비스의 실제 운영 상태를 보증하지 않는다.
- 첫 번째 업무는 사용자가 지정한 Google Forms 제출 폼으로 연결한다. 실제 제출 완료나 인증은 이 홈페이지에서 처리하지 않는다.
- 준비 중 카드는 클릭 가능한 가짜 링크 대신 `aria-disabled="true"`인 비대화형 콘텐츠로 표시한다. hover 시 이용 가능한 것처럼 움직이지 않는다.
- 실제 링크는 카드 전체가 클릭 영역이다. 키보드 포커스 윤곽과 본문 바로가기 링크를 제공한다.
- 불필요한 로그인, 개인정보 수집, 제출 폼, 관리자 기능, 가상의 이용 통계를 추가하지 않는다.

## 7. 유지보수

루트 `index.html`과 `styles.css`가 HTML 배포본의 원본이다. 원본 이미지 세 개는 보존한다. 사용자의 후속 지시에 따라 산출 범위는 로컬 HTML 및 구성 파일로 한정한다. 변경 시 `로컬-홈페이지/`와 `홈페이지-배포용.zip`을 갱신하고 온라인 재배포는 진행하지 않는다. 기존 `media-portal/`은 이전 검토용 자료로 보존하며 로컬 실행에 필요하지 않다. 업무 변경 시 카드 명칭·링크·상태·이용 가능 개수를 함께 수정한다.

## 8. 사용자 유형별 탭 구조

- 상단 소속 영문 표기는 `Department of Media`, 전체 제목은 `경희 미디어 업무 자동화 Portal`로 고정한다.
- 업무 메뉴명에서는 `경희대`, `경희대학교`, `미디어학과`를 반복하지 않는다.
- 탭은 `학생용`, `교수용`, `범용` 순서이며 각 패널은 PC에서 4열 × 3행, 총 12개 타일을 표시한다.
- 학생용에는 `졸업논문 제출`, 교수용에는 `교수 연구실적 제출`을 첫 타일로 둔다. 그 외 타일은 `업데이트 예정`이다.
- 탭은 WAI-ARIA tab/tabpanel 관계를 사용하고, 좌우 방향키·Home·End 키로 이동할 수 있다.
