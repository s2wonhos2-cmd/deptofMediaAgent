# 경희 미디어 업무 자동화 Portal

이 프로젝트는 HTML과 구성 파일만 산출합니다. 이후 수정은 로컬 파일과 배포용 ZIP에만 반영하며, 온라인 게시·재배포는 별도 요청이 있을 때만 진행합니다.

## 바로 사용하기

`index.html`을 브라우저에서 열면 홈페이지를 볼 수 있습니다. 별도 설치, 로그인, 서버 실행 없이 동작합니다. `index.html`, `styles.css`, `script.js`, `khhu-main.jpeg`, `대학휘장-02.jpg`를 같은 폴더에 유지하세요.

`로컬-홈페이지/`와 `홈페이지-배포용.zip`에 필요한 파일만 모아두었습니다. ZIP을 푼 뒤 `index.html`을 열거나 해당 폴더를 로컬 웹 서버의 문서 루트에 복사하세요. 서버 설치와 실행은 이번 산출물에 포함하지 않습니다. 원본 사진과 휘장은 수정하지 않았습니다.

필수 파일은 `index.html`, `styles.css`, `script.js`, `khhu-main.jpeg`, `대학휘장-02.jpg` 다섯 개입니다. `DESIGN_RULES.md`와 `README.md`는 관리용 문서이며 웹 서버에서 제공할 필요는 없습니다. Node.js, npm, 빌드 과정, 데이터베이스는 필요하지 않습니다. `script.js`는 세 사용자 탭의 전환과 키보드 탐색만 담당합니다. 페이지 표시는 인터넷 없이 가능하지만 Google Forms와 경희대학교 외부 링크 이용에는 인터넷 연결이 필요합니다.

## 구현 내용

- 상단 소속 표기: `Department of Media`.
- 전체 제목: `경희 미디어 업무 자동화 Portal`.
- 학생용, 교수용, 범용 순서의 탭. 각 탭은 4열 × 3행, 업무 타일 12개.
- 학생용 첫 업무: `졸업논문 제출` 준비 중.
- 교수용 첫 업무: `교수 연구실적 제출` 이용 가능. 지정된 Google Forms로 연결.
- 범용 및 나머지 타일: `업데이트 예정`.
- 태블릿 3열, 모바일 2열 또는 1열. 작은 화면과 확대 보기에서는 자연스러운 스크롤을 허용.
- 개인정보를 수집하거나 저장하지 않으며, 제출·인증 처리는 연결된 외부 서비스에서 수행.

## 수정하기

색상·배치·스타일은 `styles.css`, 탭과 타일 제목·링크는 `index.html`, 탭 동작은 `script.js`에서 수정하세요. 적용할 디자인 기준과 공식 자료 출처는 `DESIGN_RULES.md`에 있습니다.

준비 중 카드를 활성화하려면 해당 `article`을 `a`로 바꾸고 HTTPS 주소를 `href`로 지정하세요. `aria-disabled`를 제거하고 `service-card active` 클래스를 사용합니다. 상태 문구와 상단의 이용 가능/준비 중 개수도 함께 수정하세요.

## 기존 검토용 프로젝트

작업 폴더의 `media-portal/`, `sync-site.mjs`, `social-preview/`, `media-portal-build.tar.gz`는 이전 온라인 검토 과정의 자료입니다. 로컬 홈페이지 실행이나 배포에 필요하지 않으며 이번 배포용 ZIP에는 포함하지 않습니다. 기존 검토 사이트는 삭제하거나 공개 범위를 변경하지 않았습니다.

## 확인 사항

HTML 구조상 탭 3개, 탭별 타일 12개, 지정된 Google Forms 연결 주소, 모든 로컬 이미지·스타일·스크립트 경로를 확인했습니다. 로컬 서버의 정상 응답을 확인했습니다. 외부 사이트의 로그인·제출 완료 검증은 수행하지 않았습니다.

PC 레이아웃은 콘텐츠 영역 1280×720 이상·확대율 100%를 기준으로 작성했습니다. 브라우저 도구 모음 때문에 실제 콘텐츠 높이가 작아지거나 글꼴 배율이 커질 경우 스크롤이 생길 수 있습니다. 텍스트를 잘라서 스크롤을 감추는 방식은 사용하지 않습니다.

첫 번째 업무는 사용자가 지정한 Google Forms 제출 폼으로 연결됩니다.
